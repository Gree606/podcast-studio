How the agent works

A small, fast LLM (Gemini Flash) acts as an agent that perceives, plans, acts and observes, and spends extra thinking only where it's needed.

1. Plan (ReAct)
Explores the chapter with tools (search, read, define), then outlines segments. Every key fact cites a passage and is verified twice (rule check + model check).
2. Write + critique (Reflexion)
Writes each segment as a dialogue; a strict critic scores it on 5 axes and the writer revises with lessons kept in memory.
3. Adaptive compute
Harder segments get more drafts; easy ones stop early. Leftover budget flows to whichever segment the critic says is weakest (after Snell et al.).
4. Fact-check + record
Every claim in the final script is checked against the book. Each line is voiced, then transcribed back by speech recognition; garbled lines are re-recorded.

After it's done, you're the reviewer: regenerate any segment with an instruction ("simpler", "add an example"). Only that segment is rewritten and re-recorded, and you can switch between versions.

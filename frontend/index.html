    How it works

    1. 📖
      Read

      The agent picks the passages to cover from your chapter.

    2. ✍️
      Write

      One call writes a 2-minute chat: Gree explains, Error606 asks.

    3. 🔎
      Check

      A second call checks every claim against the book and fixes any that aren't there.

    4. 🎙️
      Record & listen back

      Each line is spoken, then heard by speech recognition. Mumbled lines are re-recorded.
